Separador de Boletos

Separe um PDF de boletos em vários arquivos ou junte vários PDFs em um só.

O arquivo é lido no seu navegador e não é enviado para nenhum servidor.

Envie um PDF com vários boletos (um por página), escolha a informação que define cada grupo e baixe um PDF por grupo, todos juntos num ZIP.

1. Arquivo

Arraste o PDF aqui ou clique para escolher Ex.: boletos.pdf

2. Separar por

0 = a própria linha do rótulo (o texto depois dele). Dica: abra “Ver o texto de uma página” abaixo e clique numa linha para usá-la como rótulo.

Busca no texto da página inteira, sem diferenciar maiúsculas. Ex.: CEP:\s*(\d{5}) agrupa pelo início do CEP.
